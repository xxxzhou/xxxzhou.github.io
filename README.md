# xxxzhou.github.io

Static site. GitHub Pages serves directly from `main`.

## Panvox

Pages are generated by `build.py` from the policy sources in the private
panvox repo (`docs/release/privacy-policy.*.md`). Edit there, then:

    python build.py && git add -A && git commit -m ... && git push

## TankLog / 缸记

Pages under `tanklog/` are generated from the TankLog repo's
`docs/release/{privacy-policy,support}.{zh,en}.md`:

    TANKLOG_DOCS=/path/to/tanklog/docs/release \
      .venv/bin/python tanklog/build.py

`markdown` is required (`python3 -m venv .venv && .venv/bin/pip install markdown`).
