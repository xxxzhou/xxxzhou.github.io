Avoxkit Support

Avoxkit is a free, local, account-free audio and video toolbox for macOS: format conversion, trimming, audio extraction, subtitle generation, image cleanup, screen recording and batch processing. If something goes wrong, or you have a suggestion, here is how to reach us.

Frequently asked questions

Where do converted files go?

When a conversion, trim, audio extraction or subtitle job finishes, click Open Output on that task in the task list to reveal the file in Finder. You can choose the output folder yourself before starting a job (standard Save dialog); if you don't, files go to the Avoxkit folder inside your Downloads folder, reachable in Finder at any time. Batch jobs mirror the original folder structure.

Do I need an internet connection?

Conversion, trimming and audio extraction work out of the box and are processed entirely on this Mac — nothing is uploaded to any server. Subtitle generation and image cleanup download a local model the first time you use them; after that they work fully offline, and the model runs only on this Mac.

Which formats are supported?

Common containers such as MP4 / MKV / MOV can be converted between each other, with H.264 or H.265 encoding and output resolution options of 2160p / 1440p / 1080p / 720p / 480p. When only the container changes, the stream is remuxed without re-encoding — fastest, and no quality loss. Re-encoding only happens when you change codec or resolution.

Why are some jobs slow?

It depends on whether the video is re-encoded. A container change (remux) usually takes seconds; changing codec or downscaling processes every frame, so time scales with duration, resolution and machine performance. Trimming keeps the original encoding, so it is nearly instant.

Which languages does subtitle generation support?

On-device speech recognition supports Chinese, English, Japanese, Korean and Cantonese. The first use of a language downloads its model; afterwards it works offline. Results can be exported as a subtitle file.

How does watermark / object removal work?

It uses a local inpainting model and runs on your Mac — images are never uploaded. Preview before saving; results depend on the background complexity.

What if a task fails?

Click the failed item in the task list to see the reason. Common causes are a damaged source file, insufficient disk space, or an output folder without write permission. Fix the cause and retry that task; successful items are unaffected.

Is Avoxkit paid? Do I need an account?

The current version is free. No sign-up or login is required, and no usage data is collected.

System requirements

macOS 12 or later, on both Intel and Apple silicon Macs.
